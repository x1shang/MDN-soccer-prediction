## 3. 噪声与评测

- 观测模型：两次观测位置各加独立各向同性高斯噪声，σ = 2 / 5 / 10 / 15 mm 四档；
  同一档内所有方法、所有 arm、所有 seed 用**同一组噪声**（seed = `9100 + σ·1e6`）。
- 点预测：混合分布均值；误差为欧氏距离（米）。
- NLL：物理单位（`-log p(Y,Z) + log|Σ_y|`），绝对/残差模型可直接比较（平移不变）。
- 区域：HDR（最高密度区域），阈值取 512 个混合样本的 `1-α` 分位；覆盖率看真值密度是否
  超过阈值；面积用 1024 个独立样本的逆密度积分，单位 m²。
- 能量评分：128 个样本（64 对），`E||X-y|| - 0.5·E||X-X'||`。
- P(goal)：512 个样本落入 `|Y|<3.66, 0<Z<2.44` 的比例；ECE 10 箱。
- 以上估计器对**所有**方法统一，便于横向比较（对应 todo 1.7）。

## 4. 五臂消融（P0 第 2 节）

| Arm | 输入 | 目标 |
|---|---|---|
| A | raw6 + σ（7 维） | 绝对 (Y,Z) |
| B | raw6 + σ（7 维） | 残差 Δ=(Y,Z)−(Y_const,Z_const) |
| C | physics16（15 物理特征 + σ） | 绝对 (Y,Z) |
| D | physics16 | 残差 |
| E | raw6 + σ + (Y_const,Z_const)（9 维） | 残差 |

固定配方：2×128 MLP + LayerNorm + SiLU，K=3 全协方差混合高斯，每样本连续噪声
U(1,20) mm，Adam lr=1e-3，cosine 100 epoch，batch 256，3 seeds（11/22/33）。

**physics16 的定义**（本仓库重建，非 `pi_res_mdn.py` 原实现）：

1–3 `v(0.05)` 中心差分速度；4–6 总加速度 `a`；7–9 气动加速度 `a−g`；
10 速率；11 切向加速度 `a_par`；12 法向加速度模 `|a_perp|`；
13 表观阻力系数 `cd_app = −a_par/(k|v|²)`；14 表观升力系数 `cl_app = |a_perp|/(k|v|²)`，
`k=ρA/(2m)`；15 恒加速到 x=11 m 的时间；16 σ。
