# UPC155 · 空中与触地后过门的配对对照 · 台式机回传

2026-11-08 · Windows 11 · Python 3.12.14 · PyTorch 2.11.0+cu128 · RTX 4080 SUPER (CUDA 12.8)

## 0. 一句话结论

加入 11,001 条触地扩展行后，**触地后过门（n=1,101）的中位误差从 0.161 m 降到 0.079 m（σ=2 mm），NLL 从 +1.49 降到 −4.02，95% 覆盖从 68.1% 回到 96.7%**；而**直接过门（n=8,899）几乎不动（中位误差差 ≤ 4 mm、NLL 差 ≤ 0.04）**。即：触地信息是必需的，加入它不产生可测代价。空中组在触地子集上的低覆盖是外推失败，不是训练轮数不够（见 §5 的 200 epoch 对照）。

空中组的选型 NLL 到第 100 轮仍在下降（best @ ep 100），因此补跑了一次 200 epoch 的空中组（同一脚本、同一 seed 11，cosine T_max 随之变 200）。

## 7. 物理先验审计（`case_bounce_audit.json`）

该审计用**宽均匀发射先验**（与 v3 神经模型的训练先验不同），30,000 proposals/stage，按 σ 分档。必须报告有效样本数，数值零不能当作严格上界：

| σ (mm) | ESS（seed 155313 / 155314） | ground_first_mass | 额外入框 mass |
|---|---|---|---|
| 2 | 102.3 / 70.0 | 0 / 0 | 0 / 0 |
| 5 | 2,132 / 1,767 | 0 / 0 | 0 / 0 |
| 10 | 2,986 / 3,792 | 0 / 0 | 0 / 0 |
| 15 | 4,385 / 4,388 | 8.1e−191 / 4.3e−175（各 21 行为正） | 同左 |

σ=2/5 mm 的 ESS 只有 70–2,132，因此那里的 `ground_first_mass = 0.0` 是**数值零，不是概率上界**；到 σ=15 mm 虽然有 21 行触地，权重仍在 1e−190 量级。结论只能写到："在宽均匀先验下，题例属于几乎不可能先触地的场景，先触地带来的额外入框质量无法用本次有限重要性采样定量。"这与题例作为直接过门案例的定位一致。

## 8. 口径、限制与建议

- **口径**：`median_m`/`p90_m` 是混合分布均值预测的点误差（未投影）；`projected_median_m` 是均值投影到 `z ≥ 0.11` 后的点误差，单列。覆盖率是 256 个 MC 样本中真实点对数密度超过 HDR 阈值的经验比例（分辨率 1/256 ≈ 0.4%），面积用重要性采样估计并取 batch 中位数——两者都是近似估计量，报告时不要写成解析值。
- **校准**：`scale_sd` 与 HDR 阈值只在独立 calibration 集上拟合（触地组的 calibration 集含 553 条触地行），测试集未参与任何拟合。所以触地组的 50% 覆盖能贴近名义值，而空中组在触地子集上虽然也做了校准，仍然只有 0.31/0.68——这正说明过自信来自模型形式外推，不是校准标量能救的。
- **不可比项**：两组的 val NLL 不可跨组比（选型集不同）；§3 里的所有数字可比（同一批测试行、同一噪声）。
- **未做**：20 万条扩容（`simulation/generate.py` + `generate_bounce_dataset.py`）没有跑——本次只交付 10 万条配对基准。若需要，命令见包内 `台式机prompt2.md`，生成器依赖包内冻结锚点，行号/发射参数/split 会保持配对。
- **建议**：论文里把"触地后过门"作为独立子集单列（n=1,101），不要把 10,000 行混合口径当成一个数；混合口径会把 0.16 → 0.079 的差距摊薄成 0.132 → 0.124。
